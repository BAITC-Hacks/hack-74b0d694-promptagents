## 3. Как работает решение

_Опишите основной пользовательский сценарий. Рекомендуемая структура:_

1. Пользователь _вводит / загружает / выбирает_ исходные данные.
2. Система _обрабатывает данные, обращается к модели или внешним сервисам_.
3. Пользователь получает _результат: рекомендацию, отчёт, ответ, визуализацию и т. п._
4. _При необходимости: пользователь может сохранить, отредактировать или отправить результат._
