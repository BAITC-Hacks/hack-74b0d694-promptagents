# Проверенные демосценарии

Источник: корневой `hackathon dataset anonymized .csv`, 66 профилей.
SHA-256: `6a724b6b7dfb5973343e68ba18dadb60fc807d87e3d78f03ee86fb26cb089f7d`.

Все шесть сценариев проверены независимым алгоритмом
`python -m scripts.check_demos` и тестами `tests/test_real_demos.py`.
API recommend пока отвечает 501: это подтверждение данных/алгоритма, не готового
пользовательского сценария. В алгоритме нет ожидаемых ID: они только в тестах.
Формула baseline: (0, price_from_kzt, id), потому что подготовленных признаков нет.
После добавления подтверждённой специализации состав подходящих останется тем
же, но порядок top-3 может измениться.

## Подтверждённые объяснения состава

1. В первых двух запросах проходят по четыре профиля; интерфейс должен сообщить
   это число и показать первые три по формуле, а не объявить, что найдено только три.
2. HK-88430 и HK-29829 свободны 10 октября и заняты 11 октября.
   HK-44923 и HK-44733 заняты 10 октября и свободны 11 октября.
   Наличие/отсутствие каждой даты проверено непосредственно в busy_dates.
   Другие изменения ранга нельзя автоматически называть занятостью.
3. В Алматы всего два флориста, оба проходят условия. Поэтому карточек две.
   У обоих max_hours=None — длительность не исключает. Это не обещание
   неограниченной работы на площадке. HK-90001 — синтетика организаторов,
   HK-39372 имеет price_imputed=True.
4. В Астане нет декораторов: отдельное состояние category_absent, без подмены города.
5. Из 10 ведущих 9 заняты 12 декабря; оставшийся не принимает корпоратив.
   Это no_match, а не отсутствие категории и не ошибка сервера.
6. Из 7 залов 5 заняты, ещё 1 исключён по стартовой цене; остаётся HK-64395.

## Точные входные параметры

```json
[
  {"city":"Алматы","category":"Ведущий","date":"2026-10-10","event_format":"корпоратив","budget_kzt":1000000,"language":"русский","duration_hours":6},
  {"city":"Алматы","category":"Ведущий","date":"2026-10-11","event_format":"корпоратив","budget_kzt":1000000,"language":"русский","duration_hours":6},
  {"city":"Алматы","category":"Флорист","date":"2026-10-11","event_format":"свадьба","budget_kzt":300000,"language":"русский","duration_hours":8},
  {"city":"Астана","category":"Декоратор","date":"2026-10-10","event_format":"свадьба","budget_kzt":500000},
  {"city":"Алматы","category":"Ведущий","date":"2026-12-12","event_format":"корпоратив","budget_kzt":1000000,"language":"русский","duration_hours":6},
  {"city":"Алматы","category":"Банкетный зал","date":"2026-11-14","event_format":"свадьба","budget_kzt":3000000}
]
```

В форме есть шесть кнопок с этими параметрами. Они вызывают настоящий
POST /api/recommend, где сейчас явно обозначена незавершённая реализация.
Общий список категорий позволяет выбрать «Астана + Декоратор».

После интеграции инженер №3 повторяет проверки через настоящий API, проверяет
объяснения и evidence, замеряет время (ориентир до 10 секунд), а инженер №2 —
отображение карточек и трёх исходов. Текущие тесты независимого алгоритма не
заменяют эти проверки. Новых синтетических профилей для демо не требуется.
