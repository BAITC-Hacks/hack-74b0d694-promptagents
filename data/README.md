# Каталог

Исходный файл `hackathon dataset anonymized .csv` находится в корне репозитория.
Его байты сохранены без изменений; SHA-256:
`6a724b6b7dfb5973343e68ba18dadb60fc807d87e3d78f03ee86fb26cb089f7d`.
`csv.DictReader` читает его с `encoding="utf-8-sig"`, `newline=""`.
Отдельная конвертация в JSONL не нужна. Корневой `index.html` — сохранённое
превью, не источник календарей.

Проверка из корня: `python -m scripts.validate_data` (в активированном окружении).
Ошибка данных даёт ненулевой код и номер строки/id при наличии.
Каталог читается при старте сервера; после замены CSV сервер нужно перезапустить.

Подтверждено: 66 уникальных id; Алматы — 50, Астана — 15, Зарубежье — 1;
synthetic — 13, price_imputed — 18, city_imputed — 8; несколько категорий — 13;
пустой max_hours — 9. Это снимок текущего файла, не ограничения будущего каталога.

Списки разделяются `|`; флаги допускают только `True`/`False`; цена — int;
max_hours — число или None из пустой ячейки; id — строка; description сохраняется
дословно. Структурированные поля имеют приоритет над description и AI.

Тестовые записи живут только в `tests/fixtures/`, не используются приложением.
Дополнительные синтетические профили на этом этапе не создаются.
